# Dream Planner

Dream Planner is a Canadian financial planning web app for exploring retirement, home buying, and education savings goals.

It uses a guided, advisor-style interface to collect a few details and generate projections based on the user's goals.

## Features

- Retirement planning and savings projections
- Home and education savings calculators
- Canadian TFSA, RRSP, and FHSA considerations
- Interactive advisor-style planning flow
- Save plans locally in the browser
- Export plan results

## Tech Stack

- Java 21
- Spring Boot
- JavaScript
- HTML / CSS
- Maven
- JUnit

Dream Planner is intended for educational planning and uses simplified assumptions. It is not financial advice.
